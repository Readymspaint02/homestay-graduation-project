# el-cascader 获取选择内容完整指南

## 🎯 概述

本文档详细介绍了如何在 el-cascader 中获取选择的内容，包括选中的值和对应的文本标签。

## 📋 获取选择内容的方法

### 1. **通过 v-model 获取选中的值**

```vue
<template>
  <div>
    <RegionCascader
      v-model="selectedRegion"
      placeholder="请选择省市区"
      @change="handleRegionChange"
    />
    
    <div class="result">
      <h3>选中的值:</h3>
      <p>{{ selectedRegion }}</p>
    </div>
  </div>
</template>

<script setup>
import { ref } from 'vue'

const selectedRegion = ref([])

const handleRegionChange = (value) => {
  console.log('选中的值:', value)
  // value 是一个数组，例如: [110000, 110100, 110101]
}
</script>
```

### 2. **通过 change 事件获取值和标签**

```vue
<template>
  <div>
    <RegionCascader
      v-model="selectedRegion"
      placeholder="请选择省市区"
      @change-with-labels="handleRegionChangeWithLabels"
    />
    
    <div class="result">
      <h3>选择结果:</h3>
      <p>选中的值: {{ selectedValues }}</p>
      <p>选中的标签: {{ selectedLabels }}</p>
      <p>完整文本: {{ selectedText }}</p>
    </div>
  </div>
</template>

<script setup>
import { ref } from 'vue'

const selectedRegion = ref([])
const selectedValues = ref([])
const selectedLabels = ref([])
const selectedText = ref('')

const handleRegionChangeWithLabels = (data) => {
  selectedValues.value = data.values
  selectedLabels.value = data.labels
  selectedText.value = data.labels.join(' / ')
  
  console.log('选中的值:', data.values)
  console.log('选中的标签:', data.labels)
  console.log('完整文本:', data.labels.join(' / '))
}
</script>
```

### 3. **通过组件引用获取选择内容**

```vue
<template>
  <div>
    <RegionCascader
      ref="regionCascaderRef"
      v-model="selectedRegion"
      placeholder="请选择省市区"
    />
    
    <div class="buttons">
      <el-button @click="getSelectedInfo">获取选择信息</el-button>
      <el-button @click="getLabelsOnly">只获取标签</el-button>
      <el-button @click="getCompleteInfo">获取完整信息</el-button>
    </div>
    
    <div class="result">
      <h3>获取结果:</h3>
      <pre>{{ resultInfo }}</pre>
    </div>
  </div>
</template>

<script setup>
import { ref } from 'vue'

const regionCascaderRef = ref()
const selectedRegion = ref([])
const resultInfo = ref('')

const getSelectedInfo = () => {
  const info = regionCascaderRef.value.getSelectedInfo()
  resultInfo.value = JSON.stringify(info, null, 2)
  console.log('完整信息:', info)
}

const getLabelsOnly = () => {
  const labels = regionCascaderRef.value.getLabels()
  resultInfo.value = JSON.stringify(labels, null, 2)
  console.log('标签数组:', labels)
}

const getCompleteInfo = () => {
  const info = regionCascaderRef.value.getSelectedInfo()
  resultInfo.value = `
选中的值: ${info.values.join(', ')}
选中的标签: ${info.labels.join(', ')}
完整文本: ${info.text}
  `
  console.log('完整信息:', info)
}
</script>

}

}

  margin-right: 10px;
}

pre {
  background-color: #fff;
  padding: 10px;
  border-radius: 4px;
  border: 1px solid #ddd;
}
</style>
```

## 🔧 实际应用场景

### 1. **表单提交时获取完整信息**

```vue
<template>
  <el-form :model="form" :rules="rules" ref="formRef" label-width="100px">
    <el-form-item label="项目名称" prop="projectName">
      <el-input v-model="form.projectName" placeholder="请输入项目名称" />
    </el-form-item>
    
    <el-form-item label="所在区域" prop="region">
      <RegionCascader
        v-model="form.region"
        placeholder="请选择省市区"
        @change-with-labels="handleRegionChange"
      />
    </el-form-item>
    
    <el-form-item>
      <el-button type="primary" @click="submitForm">提交</el-button>
    </el-form-item>
  </el-form>
</template>

<script setup>
import { ref, reactive } from 'vue'

const formRef = ref()
const form = reactive({
  projectName: '',
  region: [],
  regionText: '' // 存储区域文本
})

const rules = {
  projectName: [
    { required: true, message: '请输入项目名称', trigger: 'blur' }
  ],
  region: [
    { required: true, message: '请选择区域', trigger: 'change' }
  ]
}

const handleRegionChange = (data) => {
  form.regionText = data.labels.join(' / ')
  console.log('区域信息:', {
    values: data.values,
    text: form.regionText
  })
}

const submitForm = () => {
  formRef.value.validate((valid) => {
    if (valid) {
      const submitData = {
        projectName: form.projectName,
        region: form.region,
        regionText: form.regionText
      }
      console.log('提交数据:', submitData)
      // 提交到后端
    }
  })
}
</script>
```

### 3. **数据回显时设置选择内容**

```vue
<template>
  <div>
    <RegionCascader
      ref="regionCascaderRef"
      v-model="selectedRegion"
      placeholder="请选择省市区"
    />
    
    <div class="buttons">
      <el-button @click="setBeijing">设置为北京</el-button>
      <el-button @click="setShanghai">设置为上海</el-button>
      <el-button @click="setGuangzhou">设置为广州</el-button>
      <el-button @click="resetRegion">重置</el-button>
    </div>
    
    <div class="result">
      <h3>当前选择:</h3>
      <p>值: {{ selectedRegion }}</p>
      <p>文本: {{ regionText }}</p>
    </div>
  </div>
</template>

<script setup>
import { ref, watch } from 'vue'

const regionCascaderRef = ref()
const selectedRegion = ref([])
const regionText = ref('')

// 监听选择变化
watch(selectedRegion, async (newValue) => {
  if (newValue && newValue.length > 0) {
    const info = regionCascaderRef.value.getSelectedInfo()
    regionText.value = info.text
  } else {
    regionText.value = ''
  }
})

// 预设的区域数据（实际使用时应该从后端获取）
const regionData = {
  beijing: [110000, 110100, 110101], // 北京市 北京市 东城区
  shanghai: [310000, 310100, 310101], // 上海市 上海市 黄浦区
  guangzhou: [440000, 440100, 440103] // 广东省 广州市 荔湾区
}

const setBeijing = () => {
  regionCascaderRef.value.setValue(regionData.beijing)
}

const setShanghai = () => {
  regionCascaderRef.value.setValue(regionData.shanghai)
}

const setGuangzhou = () => {
  regionCascaderRef.value.setValue(regionData.guangzhou)
}

const resetRegion = () => {
  regionCascaderRef.value.reset()
}
</script>
```

## 🔍 常见问题

### Q: 如何获取选中的完整路径文本？
A: 使用 `@change-with-labels` 事件或调用 `getSelectedInfo()` 方法。

### Q: 如何设置默认值并显示对应文本？
A: 使用 `setValue()` 方法设置值，组件会自动获取对应的文本标签。

### Q: 如何处理异步加载的标签获取？
A: 组件内部已经处理了异步逻辑，使用 `async/await` 确保数据正确获取。

### Q: 如何自定义标签分隔符？
A: 可以通过修改 `getSelectedInfo()` 方法中的 `join(' / ')` 部分来自定义分隔符。
